# Custom String Class in C++

A custom dynamic C++ String library implementing manual memory management, operator overloading, and fundamental C-string algorithms without using `std::string`.

 ## Key Features
* **Dynamic Memory Allocation:** Custom allocation using `new` and `delete[]` to manage memory safely.
* **OOP Concepts:** Implemented Copy Constructor, Assignment Operator (`operator=`), and Destructor.
* **Operator Overloading:** Custom behavior for `+`, `==`, `!=`, `<<` (ostream), and `>>` (istream).
* **String Operations:** Implementations for `strcpy`, `strncpy`, `strcmp`, `strncmp`, `strcat`, `strncat`, `strrev`, `strupr`, `strlwr`, `strchr`, `strrchr`, `strstr`, and `strlen`.
